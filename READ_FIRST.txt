GITHUB UPLOAD
1. Unzip this download.
2. Open Tanneywanney25/ibm_submission on GitHub at the repository root.
3. From the main branch dropdown, create a branch named ibm-benchmark-evidence.
4. Choose Add file > Upload files.
5. Drag README.md and the docs folder into the upload area together.
   Do not drag their outer containing folder or this READ_FIRST.txt file.
6. Use this commit message: Add IBM Z CPU and accelerator benchmark evidence
7. Commit, then open a pull request from ibm-benchmark-evidence into main.
8. Review the changed files and merge when ready.

This package contains only documentation and the standalone benchmark evidence.
The existing frozen results describe a different workload and remain in place.

If a teammate changed README.md or docs/SUBMISSION.md after commit 543ebde,
use the existing GitHub diff to keep their newer text while adding the new
benchmark section and link. The new dated benchmark folder can be uploaded as-is.
